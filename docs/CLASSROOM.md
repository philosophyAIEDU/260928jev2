# 강사용 실습 자료 · JEV 상권 탐색 실습실

## 수업 목표 (45분)

- 공공데이터의 **점포 수**와 **매출·창업 성공 가능성**을 구분한다.
- Choice, Score, Noul의 질문과 응답을 읽는다.
- AI의 분류 결과를 현장에서 검증할 질문으로 바꾼다.

## 준비물

1. 앱을 실행한 주소. API 키가 없는 수업은 **키 없이 예시 보기**만으로 가능합니다.
2. 인터넷이 연결된 브라우저. 실제 호출은 교사 또는 개인의 TypeSafe JEV 키와 Netlify 함수가 필요합니다.
3. 이 문서와 [`scenarios.csv`](scenarios.csv). 엑셀에서도 열 수 있는 UTF-8 CSV입니다.

## 45분 진행

| 시간 | 학생 활동 | 질문 |
|---|---|---|
| 0–8분 | 시도, 시군구, 업종 선택 | 이 숫자는 무엇을 세었을까요? |
| 8–18분 | 두 지역의 같은 업종 비중 기록 | 점포 수와 비중은 왜 다를까요? |
| 18–28분 | CSV의 사례를 메모로 입력, 예시 또는 실제 분석 | 어떤 정보가 없어서 판단이 어려울까요? |
| 28–38분 | Choice·Score·Noul과 원본 JSON 읽기 | 확률과 점수는 어떤 질문의 답인가요? |
| 38–45분 | 현장 조사 질문 3개 작성, 다른 지역과 비교 | 다음에 무엇을 확인할까요? |

## 확장 활동 (추가 20~30분)

| 활동 | 사이트 위치 | 진행 |
|---|---|---|
| 왜 구조화된 답인가 | ① JEV 이해하기 | “표로 옮기기”를 누르고 대화형 답을 표에 옮기기 어려운 이유를 말해 봅니다. |
| 확률 읽기 | ① 질문 유형 슬라이더 | Choice에서 1·2위 확률을 비슷하게 맞추고 해석 문장이 어떻게 바뀌는지 봅니다. |
| 메모가 답을 바꾼다 | ② 실습실 | 같은 지역에서 메모에 임대료·시간대를 더하며 예시 결과와 체크리스트 변화를 관찰합니다. |
| 지역 비교 | ③ 비교 보드 | 모둠별로 2~3곳을 저장하고 CSV로 내보내 발표합니다. |
| 질문 설계 | ④ 질문 설계 | 우리 모둠만의 choice 또는 noul 질문을 만들어 형식 검사를 통과시킵니다. |
| 마무리 | ⑤ 퀴즈 | 7문항을 풀고 틀린 문항의 해설을 함께 읽습니다. |

## 쉬운 설명

- **Choice**: 여러 이름 중 하나를 고릅니다. 이 앱에서는 `밀집 / 상대적으로 적음 / 혼합 / 근거 부족` 중 하나입니다. 결과의 `confidence`와 선택지별 `probabilities`를 확인합니다.
- **Score**: 순서가 있는 단계 사이의 점수입니다. `0~3`은 **현장 조사 우선순위**이며 매출이나 수익률 점수가 아닙니다.
- **Noul**: 예/아니요 질문에 대한 **예일 확률(0~1)**입니다. 이 앱에서는 “창업 판단 전에 추가 조사가 필요한가?”입니다.
- **규칙으로 만든 예시**: 업종 비중의 비율로 화면 흐름을 보여 줍니다. 표시된 확률은 임의 값이고 AI가 계산하지 않았습니다.

## 강사 시연 예시

서울특별시의 시군구 한 곳과 `음식`을 선택합니다. 그 지역의 음식점 수를 전체 점포 수로 나눠 비중을 확인합니다. 시도 비중과 비교하되, 높다는 이유만으로 경쟁이 불리하다고 단정하지 않습니다. “점심 손님이 많은 골목인지 확인하고 싶다”는 메모를 넣고 JEV 답을 확인합니다. 실제 응답이 상식과 다르면, 그 이유를 토론하고 메모에 임대료·시간대·고객층 등 관찰한 사실을 더 적어 다시 비교합니다.

## 개념 확인 정답 예시

1. `점포 수 = 고객 수`인가요? → **아니요.** 개별 상호의 존재를 세었으며 수요나 매출 자료가 없습니다.
2. 시군구 음식 업종 2,000곳 / 전체 20,000곳이면 비중은? → **10%**.
3. 시도 비중 8%와의 차이는? → **2%p**. 2%라는 표현과 구별합니다.
4. Noul 0.9가 창업 성공률 90%인가요? → **아니요.** “추가 근거 필요”라는 질문에 대한 예 응답값입니다.

## 지도 시 유의

데이터는 2026년 6월 스냅샷입니다. 인구, 유동인구, 폐업, 임대료, 매출과 인허가를 포함하지 않습니다. 비중의 분모는 점포 수이고 인구나 면적이 아닙니다. JEV는 **정해 둔 질문에 구조화된 답**을 반환하며 근거를 생성하는 상담 챗봇이 아닙니다. 실제 창업 의사 결정에는 현장 조사와 별도 자료가 필요합니다.
